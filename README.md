# heliocarmo.com.br

Site pessoal e portfólio de Hélio Henrique do Carmo: automação de processos, IA aplicada a documentos, dashboards e aplicações web.

Site estático em HTML, CSS e JavaScript puro, sem dependências e sem build, publicado com GitHub Pages.

## Rodar localmente

Abra o `index.html` no navegador ou rode `python -m http.server` e acesse `http://localhost:8000`.
